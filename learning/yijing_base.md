# 易经基础（自修笔记）

## 核心框架

### 阴阳
- 阴（--）：柔、静、暗、下、内
- 阳（—）：刚、动、明、上、外
- 阴阳互根、消长、转化

### 三才
- 天（上爻）、人（中爻）、地（下爻）

### 八卦（三爻）
乾☰天健父、坤☷地顺母、震☳雷动长男、巽☴风入长女、坎☵水陷中男、离☲火附中女、艮☶山止少男、兑☱泽悦少女

### 六十四卦（八卦两两相重）
卦序：乾坤屯蒙需讼师，比小畜兮履泰否…（下济→上经30卦，下经34卦）

关键卦：
- 乾（䷀）：天行健，君子以自强不息
- 坤（䷁）：地势坤，君子以厚德载物
- 泰（䷊）：天地交而万物通
- 否（䷋）：天地不交而万物不通
- 既济（䷾）：事已成，防倾覆
- 未济（䷿）：事未成，有希望（最后一卦）

### 占卜法（三枚硬币）
1. 抛6次得6爻，从下往上记为初、二、三、四、五、上
2. 少阳（—）少阴（--）为静爻，老阳（○）老阴（×）为变爻
3. 本卦 + 变卦 = 综合解读
4. 用神：世爻（自己）应爻（对方）六亲（生克关系）

## 实用场景
- 币圈分析：乾=大涨/突破，坤=震荡/筑底，坎=下跌/风险，离=热度/泡沫
- 新闻时局：泰卦=和平/合作，否卦=对抗/封锁，既济=风险临近，未济=变局开端
- 占卜三问：1) 问势不问事 2) 问己不问人 3) 问远不问近
