# 黄帝内经·素问基础（自修笔记）

## 阴阳五行

### 五行生克
- 相生：木→火→土→金→水→木
- 相克：木→土→水→火→金→木
- 对应：木(肝/春/东/风)、火(心/夏/南/暑)、土(脾/长夏/中/湿)、金(肺/秋/西/燥)、水(肾/冬/北/寒)

### 五脏六腑
- 五脏（藏精）：心、肝、脾、肺、肾
- 六腑（传化）：胆、胃、大肠、小肠、膀胱、三焦
- 心主血脉、肝主疏泄、脾主运化、肺主气、肾主水

### 五运六气（核心应用）
- 五运：木运、火运、土运、金运、水运（每年一运）
- 六气：厥阴风木、少阴君火、少阳相火、太阴湿土、阳明燥金、太阳寒水
- 推算当年运气可预判：疾病流行趋势、气候异常、农业收成

## 养生核心
1. 法于阴阳：顺应四时作息
2. 和于术数：适度运动
3. 食饮有节：饮食节制
4. 起居有常：规律作息
5. 不妄作劳：劳逸结合
6. 形与神俱：身心统一

## 实用场景
- 健康建议：根据季节判断易发疾病
- 时局分析：五行流转判断经济周期
- 币圈：木(新兴产业)、火(热度产业)、土(稳健资产)、金(避险资产)、水(流动性资产)
