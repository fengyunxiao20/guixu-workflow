# 奇门遁甲基础（自修笔记）

## 核心框架

### 三盘
- 天盘（九星）：天蓬（贪狼）、天芮（巨门）、天冲（禄存）、天辅（文曲）、天禽（廉贞）、天心（武曲）、天柱（破军）、天任（左辅）、天英（右弼）
- 地盘（九宫八卦）：坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九
- 人盘（八门）：休（坎-休闲）、生（艮-生机）、伤（震-破坏）、杜（巽-隐藏）、景（离-声势）、死（坤-终止）、惊（兑-惊恐）、开（乾-开创）

### 八神（值符、腾蛇、太阴、六合、白虎、玄武、九地、九天）

### 三奇六仪
- 三奇：乙（日奇）、丙（月奇）、丁（星奇）
- 六仪：戊己庚辛壬癸

### 排盘四步
1. 地盘定局（阳遁/阴遁）
2. 天盘装星
3. 人盘定门
4. 八神布位

## 实用场景
- 时局判断：开门+天心=战机成熟，死门+天芮=避让
- 投资时机：生门+天辅=入场良机，惊门+天柱=离场信号
- 战斗/冲突：伤门+白虎=正面冲突，杜门+六合=暗中周旋
